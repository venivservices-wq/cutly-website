How to edit your video with comments

Cutly teamNov 13, 20261 min read

Leave a comment anywhere in your video, tell Cutly what you want changed, and it will make the edit for you.

1. Play the video and pause where you want a change

2. Write a comment

3. Once you have written a few comments, run the edit

Bonus: You can also use / commands for quick fixes

Enter / in the comment box to see the command list. Pause the video and send the command to run it.
