How to help Cutly find duplicate takes

Cutly teamNov 13, 20263 min read

Cutly uses AI to find repeated takes and keep the best version. AI is not perfect and can make mistakes, so a few simple habits can help Cutly get better results.

1. Repeat the whole sentence

If you make a mistake, start the sentence again from the beginning instead of repeating just the last few words.

This helps Cutly compare both tries and be more confident that you said the same thing again.

2. Take a short pause before trying again

After making a mistake, pause for a moment before saying the sentence again.

This helps Cutly see where one try ends and the next one starts.

3. Use the same words when trying again

When you say a sentence again, try to use the same words as before.

You don't have to say it exactly the same way, but using similar words helps Cutly find both takes.

4. Record somewhere quiet

Try to avoid loud music, loud background sounds, or other noises while recording.

When your voice is clear, Cutly can understand your words better and find repeated takes more easily.

Examples Cutly is likely to miss

These are the hardest mistakes for Cutly to detect. Try to avoid them when recording.

Starting over halfway through a sentence

Cutly may cut only part of the repeated sentence, leaving the two takes awkwardly stitched together.

Mistake"It was a... it was affordable."
Fix"It was affordable." (pause) "It was affordable."

Repeating yourself with no pause in between

The transcription model may register only one take if there is no pause between them, making it much harder for Cutly to find the repeat.

Mistake"They're long they're long and baggy." (no pause between the takes)
Fix"They're long and baggy." (pause) "They're long and baggy."
